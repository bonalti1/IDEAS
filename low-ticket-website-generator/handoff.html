The $49 website generator

A roofer or fence contractor taps an ad, fills in six fields, and sees their own finished website in under a minute. If they like it, they pay $49 and it goes live, with no human involved. This page covers what we want, every frontend screen, where the code lives, and the issues found while running it end to end.

The six templates

Templates 1 to 3 serve existing paying clients, and their output must stay byte-identical. Templates 4 to 6 were added later. The "customized" set uses a draft with a logo, four job photos, a color, a license, services, AI copy, and socials.

Purchase → live site

These come from a real HMAC-signed checkout.session.completed webhook for $4900 with client_reference_id=pagina-<id>, sent to the local server.

Local-run caveats: the widget's satellite map is black because no Google key was set. The hero is a gradient because hero-fence.jpg and hero-roof.jpg are not in the snapshot. The AI copy is a canned variant because no AI key was set.

Findings from this run

Each one was confirmed in the code. Number 1 was also reproduced with a second purchase.

HighAn existing customer who buys the $49 page is downgraded and gets no site.

The webhook matches existing accounts by Stripe customer, email, or phone. On a match it sets plan = "pagina", so a $67 app customer becomes site-only and loses measuring, and the draft is never published. /api/checkout-result stays ready:false, so /bienvenida times out to WhatsApp.

server/index.mjs L444–560
MediumThe published phone is not the phone the buyer approved.

The profile merges {...fromDraft.profile, phone}, so the Stripe checkout phone overwrites the draft phone. The preview showed (956) 555-0188, and the live site showed the checkout number.

server/index.mjs L481
MediumFence sites say "Techos en …".

The zone headings are hard-coded instead of using TRADE_WORDS. This is visible in the published fence site's "Zonas que cubrimos" section.

server/templates.mjs L397, 443, 511, 627, 670
LowAccented names produce broken slugs.

"González Fencing" becomes /site/gonz-lez-fencing. Run normalize("NFD") and strip diacritics before slugifying. This affects most of the target market.

server/db.mjs L139
LowThe Clásica hero has no side gutter on mobile.

The headline and the city pill touch the screen edges at 390px.

server/templates.mjs, template 1 hero CSS
LowHero photos are missing from the snapshot.

Add public/landing/hero-fence.jpg and hero-roof.jpg. The code is file-gated and falls back to a gradient.

server/index.mjs L7643
InfoThe style picker costs 12 page loads on a phone.

Six bare=1 renders each load the widget iframe as soon as step 1 opens. Consider suppressing the widget in bare mode.

Draft shape

pgdraft:<12-hex> = {
  trade: "fence" | "roofing",
  biz, name, phone, city, years,     // 1..60
  template: "1".."6", color,         // PG_COLORS or ""
  logo,       // data:image/png|jpeg ≤300KB
  tagline,    // ≤140
  about,      // ≤450
  area, license, services[≤8],
  photos[≤6], // ≤320KB each, ≤1.5MB total
  facebook, instagram,               // https only
  aiN, vN, created
}
