# Draft House brand

Source logos: `public/brand/logo-draft-house.jpg` and `public/brand/logo-drafting-house.jpg`.
Vector mark for the web: `public/brand/mark.svg`.

| Token | Value | Use |
|---|---|---|
| `--brand-paper` | `#F7F7F7` | Page and panel background |
| `--brand-ink` | `#111111` | Wordmark, headings, body text |
| `--brand-brown` | `#4E3C30` | Compass mark, rules, primary buttons |
| `--brand-hair` | `#D9D6D1` | Borders and dividers |
| `--brand-muted` | `#6B6560` | Secondary text |

Font: **Montserrat** (Google Fonts), weight 400 for the wordmark, 500 to 600 for UI.
Wordmark is always uppercase with wide tracking. Keep the brown rule between the two words in the stacked lockup.

Drawing labels inside the 3D viewer stay monospace on purpose: it reads as a drafting convention and keeps dimensions aligned.
